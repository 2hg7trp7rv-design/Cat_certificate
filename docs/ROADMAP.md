# Roadmap

## Phase 1 — Creator Preview v0.2.0

- 現実時刻
- 朝食・夕食
- 就寝時刻
- 猫・犬
- 4段階成長
- 端末保存
- 制作者用時間操作

## Phase 2 — 触れ合い品質

- 撫でる場所と速度による反応差
- 鳴き声、耳、目、しっぽ、呼吸の改善
- 猫と犬の自律行動差
- 留守中の出来事記録
- 犬の短い散歩

## Phase 3 — iPhone実機確認

- Vercel確認版をiPhoneで操作
- 音、触覚、Safe Area、復帰、保存を検証
- 問題を修正してWeb骨格を固定

## Phase 4 — iOS版

- Capacitorを基礎にiOSプロジェクトを生成
- ローカル通知、ネイティブ触覚、アプリ復帰を実装
- TestFlightで実機確認
- App Store審査と公開

一般向けWebゲームは作らず、Webは制作確認に限定する。
