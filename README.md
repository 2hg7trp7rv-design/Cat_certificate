# Tail Room

家で猫や犬を飼えない人が、スマートフォンの中で1匹のペットと本当に暮らしていると感じられるゲームを作り、App Storeで公開するプロジェクトです。

## Work開始時に最初に読む資料

**[docs/WORK_HANDOFF.md](docs/WORK_HANDOFF.md)**

このファイルが、最新の商品方針、技術方針、現行コードの扱い、禁止事項、次の作業順序をまとめた最優先の引き継ぎ資料です。
