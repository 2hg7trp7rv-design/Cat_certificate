# Tail Room — Cat Core Creator Preview 0.5.0

家で猫や犬を飼えない人が、スマートフォンの中で1匹のペットと暮らす体験を作るプロジェクトです。一般公開Webゲームではなく、スマートフォンから制作確認するためのWeb版を先に作り、完成後にiOSアプリへ移行します。

## v0.5.0

旧v0.4の「正面の猫＋状態カード＋常設コマンド」という構造を止め、猫1匹の生活コアへ絞って再構築しました。

- 画面全体を部屋として使い、部屋を角丸カードに閉じ込めない
- 常設の4コマンドボタンを廃止し、食器・窓・寝床・おもちゃ箱へ直接触れる
- 座る、歩く、食べる、眠る、毛づくろい、伸び、飛びつく等の姿勢別SVG
- 食事は「置く→気づく→歩く→嗅ぐ→食べる→満足する」まで画面上で進行
- 撫でる場所と速度によって反応を変える
- 現実時刻、空腹、睡眠、約120日の成長、留守時間を保存
- 保存形式を `tail-room-state-v5` へ更新
- 犬は猫の生活コアが商品品質へ達した後、専用骨格と専用行動で追加

品質確認: `npm run check`

ネイティブ通知、実音声、iOS触覚、ウィジェット、TestFlight、App Store提出は未実装です。
