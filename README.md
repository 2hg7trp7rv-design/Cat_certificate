# Tail Room — Creator Preview 0.4.0

猫や犬を飼えない人が、スマートフォンの中で1匹のペットと暮らす体験を検証するための制作者専用Web版です。一般向けWebゲームとして運用せず、完成後はiOSアプリへ移行します。

旧版の「ボタンを押すと文章だけが出来事を説明する」構造を廃止し、画面上で因果関係が見える縦切り版へ再構築しました。

- 起動後すぐに猫・犬へ触れる3段階オンボーディング
- 猫と犬で異なる身体、顔、耳、しっぽ
- 呼吸、瞬き、しっぽ、毛づくろい、伸びの自律動作
- 頭・身体・しっぽを判定する直接タッチ
- 食器へ食事が入り、気づく、歩く、匂いを確認する、食べる、戻る一連の動作
- 指で動かす猫じゃらし／ボール
- 猫は窓辺へ探索、犬は玄関へ向かう短い散歩演出
- 就寝時刻または休む操作で寝床へ移動
- 現実時刻、空腹、睡眠、4段階成長、留守時間の状態計算
- 保存形式を `tail-room-state-v4` に一本化
- 古いService Workerとキャッシュを自動解除

品質確認: `npm run check`

これは完成品ではありません。ネイティブ通知、iOS触覚、実音声、ウィジェット、TestFlight、App Store提出は未実装です。
