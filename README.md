# Tail Room — Creator Preview 0.6.0

家で猫や犬を飼えない人が、スマホの中で一緒に暮らす体験を作るプロジェクトです。

## v0.6の変更

- 猫・部屋・家具をSVG/CSS図形で描く方式を停止
- 全画面ラスタービジュアルへ変更
- 初回4時刻入力を廃止し、触れる→名前→暮らし開始へ短縮
- 最初の3分間は現実の就寝時刻より初対面を優先
- 制作者メニューは名前部分の長押しで表示
- タッチ端末で白いhover枠を出さない
- 撫でている最中から触覚/波紋フィードバック
- 現実時刻、空腹、成長、セーブ、時間送りは維持

## 現状

本版は視覚層の根本差し替えを確認するCreator Previewです。ラスタービジュアルはまだ最終アートではありません。猫の本格的な中間フレームアニメーション、音、iOSネイティブ通知、TestFlightは後続工程です。
