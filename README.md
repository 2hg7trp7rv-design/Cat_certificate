# Tail Room — しっぽのいる暮らし

家で猫や犬を飼えない人が、スマートフォンの中で1匹のペットと暮らすためのゲームです。

このリポジトリは、**制作者確認用のスマートフォンWeb版**と、将来のiOSアプリへ引き継ぐ共通ゲームロジックを収録しています。一般向けのWebゲームとして公開する計画はありません。現在は **Creator Preview v0.2.0** です。

## v0.2.0で確認できること

- 猫または犬、毛色、性格、名前の選択
- 起床・朝食・夕食・就寝時刻の設定
- 現実時刻に連動する朝・昼・夕方・夜
- 食事時刻を過ぎた時の空腹状態
- 設定した就寝時間に連動する睡眠
- 指で撫でる、食事を置く、おもちゃで遊ぶ
- 猫と犬で異なる反応文と動き
- 4段階の簡易成長（子ども→成体、約120日）
- アプリを閉じていた時間の経過反映
- 端末内セーブ
- 制作者用の `+6時間 / +1日 / +30日` 時間確認
- ブラウザ通知の動作見本

## 画面確認

制作者用Vercel URLで、初回設定・猫の部屋・成体の犬・制作者設定をスマートフォンから確認します。

## 実行と品質確認

```text
npm ci
npm run check
npm run dev
```

Node.js 22以上を使用します。ゲーム本体は外部ランタイム依存のない静的構成です。

## 主な構成

- `src/app.js`：画面、入力、音、通知見本、制作者機能
- `src/game-state.js`：現実時刻、食事、睡眠、成長、保存
- `src/pet-art.js`：猫・犬の独自SVG描画
- `src/styles.css`：スマートフォン縦画面UI
- `tests/`：状態ロジックの自動テスト
- `public/`：Web確認版のアイコン、Manifest、Service Worker
- `capacitor.config.json`：後工程のiOS化に備えた設定
